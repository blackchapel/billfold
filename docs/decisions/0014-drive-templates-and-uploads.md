# 0014 Full Drive access, filing templates and documents on hand-typed bills

**Context.** Billfold could only see folders it had created itself (`drive.file`), so it could not file into folders that already exist (an existing `bills` folder full of earlier months). People also want their own file names, and a bill typed in by hand had no way to carry its document.

**Decisions.**
- **Scope.** Drive connections now ask for `https://www.googleapis.com/auth/drive`. This is a *restricted* scope: the OAuth consent screen of project A (where it was added) needs Google's verification before people outside the test list can use it; that is the owner's to complete. The code and the privacy policy only claim what Billfold does with it: look up folders by name, create missing ones, upload bill files, and download only the files Billfold itself stored (for email attachments).
- **What was granted is recorded.** Google says which scopes it granted; the connection keeps `driveAccess` ("full" or "files") in its non-secret settings. Connections made earlier have neither, so they show **needs more permission** and keep working with the old layout; **Reconnect** upgrades them. A folder path on a connection that cannot see existing folders is refused with a clear message instead of quietly creating a second "bills" folder.
- **Templates per source** (`sources.file_name_template`, `sources.folder_template`, migration `0008`). Plain find-and-replace, never evaluated (`lib/name-template.ts`): `{{Mon}}` Oct, `{{mon}}` oct, `{{MON}}` OCT, `{{Month}}` October, `{{month}}`, `{{MONTH}}`, `{{yy}}`, `{{year}}`/`{{yyyy}}`, `{{mm}}`, `{{period}}`, `{{source}}`, and `{{original}}` (file names only). Names are case-sensitive because the case of the placeholder is the case of the result. They are checked when saved (unknown names, slashes, `.`/`..`, depth and length limits, stray braces) with the same messages on screen while typing and on the server, and the form shows a live example. Empty means the old layout. Already-filed bills are not renamed or moved. The month is the run's month (the month the bills belong to), not the day the run happens.
- **Folders.** The path starts at My Drive, reuses the oldest folder with that name at each level and creates only what is missing. A name already present in the folder gets " (2)", never an overwrite. Folder ids are cached (ADR 0013).
- **Add a bill with its document.** The Add bill form takes an optional file (PDF, PNG, JPG or WebP, up to 4 MB because Vercel refuses larger request bodies), a Drive and a folder path (same placeholders, filled from the bill's month). The file keeps the name it was uploaded with (cleaned of characters Drive dislikes; the right extension is added only when missing). The file type is decided from its first bytes, not from its name, so a program renamed `.pdf` is refused. If the upload to Drive fails the bill is not added.
- **Gemini.** Because bill PDFs come from Gmail, and Google's Limited Use rules forbid training models on that data, Gemini is used only when `GEMINI_NO_TRAINING_CONFIRMED=1` is set next to the key (a paid, billing-enabled key). Without it the built-in text reader is used. The free tier may train on content, so it must not be used with Gmail data.

**Consequences.** Full Drive access is a bigger permission, so the privacy policy, terms and setup guide say so plainly. Reconnecting every Drive once is needed to use folder paths.
